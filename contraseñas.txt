IMPORTANTE DE SEGURIDAD:
Este archivo contiene únicamente plantillas, placeholders y claves de ejemplo 
para documentar la estructura de configuración requerida por la solución.
Las credenciales reales y de producción en Azure deben generarse con contraseñas 
fuertes (mínimo 12-16 caracteres, mayúsculas, minúsculas, números y símbolos)
y mantenerse FUERA del repositorio público en variables de entorno seguras 
o en Azure Key Vault.

AZURE_VM_ADMIN_USERNAME=jonaazure

AZURE_VM_PUBLIC_IP=158.23.165.154
SSH_COMMAND_EJEMPLO=ssh jonaazure@158.23.165.154

--------------------------------------------------------------------------------
2. CREDENCIALES DE BASE DE DATOS SQL SERVER / AZURE SQL 
--------------------------------------------------------------------------------
MSSQL_APP_USER=4to_A
MSSQL_APP_PASSWORD=4to_A
MSSQL_PORT=1433

Cadena de Conexión Seguridad:
ConnectionStrings__SeguridadConnection=Server=sqlserver,1433;Database=Seguridad;User Id=4to_A;Password=EjemploAppPass2026!#;Encrypt=False;TrustServerCertificate=True

Cadena de Conexión Categoría:
ConnectionStrings__CategoriaConnection=Server=sqlserver,1433;Database=categoria;User Id=4to_A;Password=EjemploAppPass2026!#;Encrypt=False;TrustServerCertificate=True

Cadena de Conexión Vehículo:
ConnectionStrings__VehiculoConnection=Server=sqlserver,1433;Database=vehciulos;User Id=4to_A;Password=EjemploAppPass2026!#;Encrypt=False;TrustServerCertificate=True

--------------------------------------------------------------------------------

6. PUERTOS Y ENRUTAMIENTO PÚBLICO EN AZURE 
--------------------
Puerto 22:    SSH (Acceso administrativo a la consola)
Puerto 5119:  API Gateway (YARP Reverse Proxy - Punto de entrada unificado)
Puerto 5260:  Seguridad.Api (Swagger y autenticación directa)
Puerto 5259:  Categoria.Api (Swagger y microservicio de categorías)
Puerto 5258:  Vehiculo.Api (Swagger y microservicio de vehículos)
Puerto 15672: RabbitMQ Management Dashboard (Monitoreo de colas y exchanges)
Puerto 5672:  RabbitMQ Protocolo AMQP (Comunicación interna entre servicios)
Puerto 1433:  SQL Server (Motor de base de datos relacional)
